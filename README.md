# 💻 Структуры данных и алгоритмы (C/C++)

Репозиторий содержит лабораторные работы за 2-й семестр, посвященные углубленному изучению языка C/C++ и реализации фундаментальных структур данных с нуля. 

Проект демонстрирует прогресс от процедурного программирования на C с ручным управлением памятью до объектно-ориентированного и шаблонного программирования на C++, включая разработку интерфейсов, юнит-тестирование и создание пользовательского интерфейса.

## 📝 Описание
В рамках данного курса были реализованы ключевые абстрактные типы данных (АТД):
- Динамические массивы и связные списки.
- Обобщенные последовательности (`Sequence`) с единым интерфейсом.
- Бинарные деревья.
Особое внимание уделено корректности кода: все структуры данных покрыты модульными тестами (через `assert` и кастомные тестовые фреймворки), а управление памятью реализовано без утечек.

## 💻 Технологический стек
- **Языки**: C (10%), C++ (90%)
- **Парадигмы**: Процедурное программирование, Объектно-ориентированное программирование (ООП), Обобщенное программирование (Templates)
- **Инструменты**: GCC / G++, Make (опционально), стандартная библиотека шаблонов (STL) для сравнения
